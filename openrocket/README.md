# OpenRocket design

`rocky.ork` is the Rocky 1 design, saved in OpenRocket 24.12.

It contains five stored flights for a DARS launch at 60 °F on a six-foot rod. Ballast is already set in each one:

| Wind | Ballast |
| --- | --- |
| Calm | 68.5 g |
| 5 mph | 66.5 g |
| 10 mph | 61 g |
| 15 mph | 53.5 g |
| 20 mph | 46 g |

Open the file in [OpenRocket](https://openrocket.info/) to inspect the rocket, change a flight, or run it from the application. To fly all five at once from the terminal, use `simulations/run.py`.
